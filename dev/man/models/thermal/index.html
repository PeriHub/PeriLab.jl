Thermal Models

The main models are thermal expansion, thermal flow and heat transfer. Specific Heat Capacity, Density and Horizon are keys of the block. Every thermal model entry accepts these shared keys:

YAML keyTypeRequiredDefaultRangeQuantityDescription
Thermal Conductivitynumberoptional—≥ 0Thermal conductivity of the material; required by Thermal Flow and used for the stable time step

Thermal Expansion

Calculates the thermal expansion of the material.

YAML keyTypeRequiredDefaultRangeQuantityDescription
Thermal Expansion Coefficientnumber or list of numbersrequiredThermal expansion coefficient, the thermal strain per temperature change: one value, or one per direction
Reference Temperaturenumberoptional—Temperature without thermal strain; 0 if not given
Thermal expansion

PeriLab supports currently only isotropic thermal expansion.

Thermal Flow

YAML keyTypeRequiredDefaultRangeQuantityDescription
Typeone of: BondBased, CorrespondenceoptionalBondBasedFormulation of the heat flow: per bond, or from the temperature gradient as in correspondence materials

Heat Transfer

YAML keyTypeRequiredDefaultRangeQuantityDescription
Heat Transfer Coefficientnumberrequired≥ 0Heat flow per surface area and temperature difference between surface and environment
Environmental Temperaturenumber or textrequiredTemperature of the surrounding medium: a number, or an expression in the time t
Allow Surface Changetrue/falseoptionaltrueRecomputes the surface in every step, so cracks and added material exchange heat too
Bed Temperaturenumber or textoptional—Temperature of the build plate: a number, or an expression in the time t; without it, faces on the plate exchange heat with the environment
Bed Heat Transfer Coefficientnumberoptional—≥ 0Heat flow per contact area and temperature difference between node and build plate; Heat Transfer Coefficient if not given
Bed Thermal Conductivitynumberoptional—≥ 0Thermal conductivity of the contact to the build plate; the heat is conducted across half the node height, i.e. Bed Heat Transfer Coefficient = 2 Bed Thermal Conductivity / height
Bed Positionnumberoptional0Position of the build plate along the last coordinate axis (z in 3D, y in 2D)

HETVAL

User-defined heat generation from an Abaqus HETVAL subroutine, compiled into a shared library like a UMAT. Its properties are given as Property_1 … Property_N.

YAML keyTypeRequiredDefaultRangeQuantityDescription
FiletextrequiredHETVAL library, relative to the input deck
Number of State Variablesintegeroptional1≥ 1Size of the state variable field passed to the HETVAL
HETVAL Material Nametextoptional—Material name passed to the HETVAL (at most 80 characters)
Predefined Field Namestextoptional—Node fields passed to the HETVAL as predefined fields, separated by spaces; Volume if not given

Model merging

In PeriLab you are able to combine models with each other, by simply adding a +. Therefore, modules can be merged and double coding can be avoided. This is necessary if you want to model the heating of a model and its expansion.

Full Model

If you want to run a full thermal model Thermal Flow + Heat Transfer + Thermal Expansion.

Model order

The order is defined by the user. Therfore, in this example first the flow, than the transfer to the environment and than the expansion will be calculated.
